## Описание
Консольное приложение для управления доступом к иерархическим ресурсам с аутентификацией пользователей.  
Программа проверяет права доступа пользователя к указанному ресурсу и возвращает соответствующий код выполнения.

## Требования к окружению
- Git Bash (Windows) или bash (Linux/macOS)
- JDK 17
- Доступ в интернет для загрузки Maven-зависимостей (первый запуск)
- Maven ставить не нужно: используется Maven Wrapper (`mvnw`, `.mvn/`)

## Гайд на запуск
Открыть Git Bash и перейти в папку с проектом (там где лежит `pom.xml`)
- cd /c/Path/To/Project

## Сборка проекта:
- ./scripts/build.sh

## Инициализация базы данных (создаст/пересоздаст H2 и заполнит таблицы):
- ./scripts/init-db.sh

## Запуск приложения:
- ./scripts/run.sh --login player --password qwerty --action read --resource data --volume 1

## Запуск автотестов (скрипт прогоняет набор кейсов и проверяет exit code):
- ./scripts/test.sh
